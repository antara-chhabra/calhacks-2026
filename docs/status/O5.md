### SDK boundary finding

Autonomy Off does not ensure native read-only tools reach the permission handler. H0 disables `Read`, `Glob`, `Grep` and `LS`; problems are sent in the prompt. A Python blacklist also cannot constrain host reads or network access: dynamically constructed paths bypass literal patterns. H0 therefore disables native Execute for **all** fighters and denies every Execute request, with no environment escape hatch. House verification strategies use mathematical re-derivation. File writes remain canonical-path checked. The wrapper is **not an OS sandbox** and the backend makes no arbitrary-code containment claim. Reintroducing Python verification requires an OS-isolated executor and validation, plus the requested PRD/ADR correction. Full hostile-persona live-match AC-04.1 is unclaimed; the actual match-IO yellow/yellow/red behavior is tested.
